## App Brainstorming (Step 4)

Favorite iOS Apps:
 
 1. Notability:
    a. Allows to personalize theme in the app.
    b. Allows to modularize the notes according to subjects and dividers.
    c. Allows to record audio while taking notes.
    
 2. Reminders:
    a. Cross-Device Sync makes this my favorite reminder app because all my tasks instantly appear on all my Apple devices
    b. Allows using Siri to create reminders by using voice commands.
    
 3. Health
    a. Allows to keep all the important information at one place. So I don't need to download multiple apps to keep information related to my health.
    b. Ability to add reminder for taking medicines. I can also customize the visual representation of reminders (like changing the color of the pill in notification).
    
 4. AllTrails
    a. It has comprehensive dataset which contains information about all the trails. I also like the filter options available like difficulty level, elevation gain, etc., that helps me decide which trail would be right for me.
    b. Offline navigation system helps me track how much distance I have covered, if I am moving in correct direction and alerts me if I take a wrong turn. It is extremely important for me because cell service is usually not available when hiking.

My dream app: **TrailBlazers** - It is a mobile application that helps to improve trail maintenance through community participation and artificial intelligence. The hikers will be able to use the app to report trail obstacles by taking a photo, which automatically captures GPS coordinates and uses AI to classify the obstruction type and severity. Users can report issues even without internet connectivity, with data syncing once connection is restored. 
    The trail authorities can use the app as a management portal with prioritized maintenance queues, work order integration, and analytical tools to identify problem areas.
